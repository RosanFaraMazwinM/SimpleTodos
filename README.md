# Simple Todos – Enhancement

A simple and interactive Todo application built using React.js. This project enhances the original Simple Todos application with additional task management features.

## 🚀 Live Demo

**[Click here to view Simple Todos](https://simplettodosapp.ccbp.tech/)**

## ✨ Features

- **Add Todos:** Add new tasks using the input field.
- **Multiple Todos:** Add multiple tasks with the same title by entering a title followed by a number (Example: `Study 5`).
- **Edit Todos:** Edit existing task titles and save changes.
- **Complete Todos:** Mark tasks as completed using checkboxes.
- **Strike-through:** Completed tasks are displayed with strike-through styling.
- **Delete Todos:** Remove tasks from the list.
- **Responsive Design:** Clean and user-friendly interface.

## 🛠️ Technologies Used

- JavaScript
- HTML5
- CSS3
